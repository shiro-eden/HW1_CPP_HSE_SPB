# Скалярное произведение

Цель задачи — научиться работать с аргументами командной строки, указателями и динамическим выделением памяти вручную.

Даны два массива вещественных чисел одинаковой длины $n$: $a$ и $b$. Вычислите их скалярное произведение:

$$
a_0 b_0 + a_1 b_1 + \ldots + a_{n-1} b_{n-1}.
$$

В этой задаче нельзя пользоваться классами и функциями стандартной библиотеки, кроме потокового ввода/вывода (`std::cin`, `std::cout`). В частности, запрещены `std::vector`, `std::string`, `std::inner_product`, `atoi` и `stoi`. Можно использовать базовые типы, условия, циклы, функции, указатели, ссылки и `new[]`/`delete[]`.

Программа должна работать за $O(n)$ времени и использовать $O(n)$ памяти. Выделять память «с запасом» нельзя. Всю выделенную память необходимо освободить.

## Формат ввода

Длина массивов передаётся как единственный аргумент командной строки:

```text
./a.out n
```

Аргумент состоит из десятичных цифр; $1 \le n \le 100\,000$.

Через стандартный поток ввода передаются сначала $n$ элементов массива $a$, затем $n$ элементов массива $b$. Числа разделены пробелами или переводами строки. Каждый элемент лежит в диапазоне от $-10$ до $10$ и записан в обычной десятичной форме без экспоненты, не более чем с шестью цифрами после точки. 

## Формат вывода

Выведите одно число — скалярное произведение. Ответ $x$ принимается, если $|x-s| \le 10^{-5}\max(1, |s|)$, где $s$ — точное скалярное произведение заданных десятичных чисел.
Если количество аргументов некорректно, завершите программу с кодом 1.

## Пример

Запуск:

```text
./a.out 3
```

Стандартный ввод:

```text
1.5 -2 0.25
2 3 -4
```

Стандартный вывод:

```text
-4
```
